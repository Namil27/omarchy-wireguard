# omarchy-wireguard

WireGuard в верхней панели Omarchy Shell. Виджет показывает состояние VPN, а меню на rofi позволяет импортировать и управлять профилями без отдельного приложения. Сетью управляет NetworkManager; существующие соединения вне проекта не меняются.

## Требования

Omarchy Shell, NetworkManager с поддержкой WireGuard, Python 3.10+, `wireguard-tools`, rofi с поддержкой Wayland, `zenity` и `notify-send`. Установщик сам добавит rofi через `omarchy pkg add rofi`, если его нет; для установки пакета система может запросить пароль в терминале. Для операций NetworkManager используется штатная авторизация Polkit. Остальные недостающие пакеты можно установить через `omarchy pkg add zenity libnotify wireguard-tools`.

## Установка

```sh
git clone https://github.com/Namil27/omarchy-wireguard.git
cd omarchy-wireguard
./scripts/install.sh
```

Установщик создаёт команду `~/.local/bin/omarchy-wireguard`, добавляет виджет `namil27.wireguard` в правую часть панели и копирует тему меню. Перед заменой существующих файлов и изменением `~/.config/omarchy/shell.json` он делает резервные копии `*.bak.*`, затем перезапускает оболочку панели. Остальная раскладка панели сохраняется. Виджет наследует цвета Omarchy Shell; меню читает палитру активной темы Omarchy и использует встроенные цвета как запасной вариант.

## Как работает

Импорт `.conf` создаёт соединение NetworkManager без активации и автоподключения. Приложение хранит UUID своих профилей в `~/.local/state/omarchy-wireguard/state.json` и управляет только ими. Обычно активен один профиль; при ошибке переключения можно восстановить предыдущий.

Долгоживущий монитор отслеживает события NetworkManager и изменения состояния приложения. Статус туннеля обновляется сразу, свежесть WireGuard handshake перепроверяется раз в 30 секунд. Наличие интерфейса не выдаётся за подтверждённую связь с сервером. Если чтение handshake ограничено правами, его можно проверить по запросу через Polkit; постоянные привилегии программе не выдаются. Неподдерживаемые параметры конфига отклоняются с номером строки; скриптовые хуки не запускаются.

## Диагностика

```sh
~/.local/bin/omarchy-wireguard status
omarchy plugin list
tail -n 30 ~/.local/state/omarchy-wireguard/app.log
python3 -m unittest discover -s tests -v
```

Журнал не сохраняет содержимое конфигов и вывод `nmcli`.

## Удаление

```sh
./scripts/uninstall.sh
```

Скрипт убирает виджет и программу, сохраняя импортированные VPN-соединения NetworkManager и локальное состояние. Если они больше не нужны, удалите их отдельно через NetworkManager. Резервные копии файлов остаются на диске.
